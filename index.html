    Backup Data Sistem

    Ekspor seluruh data Warga, Keuangan, dan Inventaris ke dalam format JSON. Berguna untuk keperluan pencadangan (backup).

    Log Riwayat Aktivitas

    Pantau seluruh perubahan data yang dilakukan oleh Admin atau Pengurus di dalam sistem.

    Koneksi Cloud Backend (Google Apps Script)

    Hubungkan SIM-RT ke Google Apps Script (GAS) untuk sinkronisasi database cloud. Masukkan URL Web App GAS Anda di bawah ini.

    Belum Punya Script Backend?

    Sistem dapat membuatkan kerangka kode Google Script otomatis yang memuat data aplikasi saat ini (sebagai data dummy awal).
